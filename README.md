# Abhijeet Khomane — Portfolio

A responsive personal portfolio highlighting my experience in data analytics, software development, AI, and IoT. The site is built with plain HTML, CSS, and JavaScript.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or use the VS Code Live Server extension to preview the site locally.

The site loads Google Fonts and Font Awesome from their CDNs, so an internet connection is needed for those external assets.

## Portfolio sections

- **About:** introduction and contact details.
- **Skills:** programming, analytics, web development, and tools.
- **Experience & Education:** Data Analyst Intern at SpacECE India Foundation and B.Tech details.
- **Projects:** IoT plant disease detection, AI-powered embedded surveillance, Learning Outcome Dashboard, and TaskFlow.
- **Certifications & Awards:** listed credentials.
- **Contact:** email, phone, social links, and contact form.
